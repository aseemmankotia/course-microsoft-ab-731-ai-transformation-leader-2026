## Chapter 6: Copilot Chat, Business Chat, and Copilot Studio for Custom Agents — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | What is Copilot Chat (Business Chat) in the Microsoft Copilot ecosystem? | The cross-app conversational entry point that lets users ask natural-language questions across Microsoft 365 apps without any custom development. Exam tip: this is the 'adopt' option in build/buy/adopt. |
| 2 | What is the primary purpose of Copilot Studio? | A low-code/no-code platform for building custom, purpose-specific conversational agents with tailored connectors, data sources, and logic. Exam tip: this is the 'build' option in build/buy/adopt. |
| 3 | Build vs Buy vs Adopt — define each in one phrase | Build = create custom agent in Copilot Studio; Buy = acquire pre-built agent (marketplace/ISV); Adopt = use out-of-box Microsoft 365 Copilot/Copilot Chat as-is. |
| 4 | When should a leader choose 'Adopt' over 'Build'? | When the need is generic cross-app Q&A/productivity assistance already covered by Microsoft 365 Copilot Chat — no custom data source or unique workflow logic required. |
| 5 | When should a leader choose 'Build' (Copilot Studio) over 'Adopt'? | When the scenario requires custom business logic, connection to proprietary/non-Microsoft data sources, or a workflow-specific agent not covered by out-of-box Copilot. |
| 6 | When is 'Buy' the right choice in the decision framework? | When a pre-built, vendor-supported agent already meets the requirement closely enough that custom development would be redundant effort. |
| 7 | What governance control is most critical before approving broad publication of a custom Copilot Studio agent? | Deploying to a managed environment with Data Loss Prevention (DLP) policies and approved connector lists enforced via the Power Platform admin center. |
| 8 | What is the recommended handoff step when a pilot custom agent proves successful and needs to scale? | Move it from an individual maker's personal environment into an IT-governed environment with ALM, monitoring, and catalog listing for enterprise reuse. |
| 9 | How does Copilot Studio typically bill for agent usage compared to Microsoft 365 Copilot? | Copilot Studio uses consumption-based billing (based on messages/sessions), separate from the per-user licensing model of Microsoft 365 Copilot. |
| 10 | What is the main cost/complexity risk of choosing 'Build' unnecessarily? | Added maker effort, connector configuration overhead, ongoing maintenance, and consumption costs — when an existing 'adopt' or 'buy' option would have met the need with less effort. |
| 11 | Common exam trap: mistaking Copilot Chat for a fully custom agent solution | Copilot Chat is an out-of-box, cross-app experience (adopt), NOT a customizable agent platform — that's Copilot Studio (build). |
| 12 | What leadership-level detail does AB-731 test about Copilot Studio (not implementation)? | What Copilot Studio ENABLES (low-code custom agent creation, business-user empowerment) — not HOW to configure topics/connectors technically. |
