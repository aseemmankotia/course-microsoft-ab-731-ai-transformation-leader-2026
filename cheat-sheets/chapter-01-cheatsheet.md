## Chapter 1 Cheat Sheet: AI Transformation Opportunities Across Business Functions

### Function → Dominant Opportunity Pattern
| Function | Pain Point | Gen AI Capability | Watch-Out |
|---|---|---|---|
| Sales | Manual prospect research, email drafting | Summarization + drafting | Autonomous deal-closing = overreach |
| Marketing | Slow content production | Drafting (copy variations) | Human review required = augmentation, not automation |
| HR | Manual screening/policy drafting | Summarization + drafting | External flashy features w/ no internal pain point = hype |
| Finance | Manual variance narrative writing | Summarization + drafting | Gen AI drafts narrative only — not the calculation itself |
| Operations | Unstructured incident data → SOPs | Summarization + drafting | Distinct from predictive maintenance/anomaly detection |
| Customer Service | High-volume, low-complexity tickets | Drafting/deflection | Complex escalations stay human |

### Automation vs Augmentation vs Transformation
| Category | Human Role | Scope of Change |
|---|---|---|
| Automation | None required | Task executes independently |
| Augmentation | Reviews/edits output | Workflow unchanged, assisted |
| Transformation | Redesigns role | Process/business model changes |

### AI-Readiness Signal Checklist (need ALL 3)
1. **Repetitive knowledge work** — high volume, low uniqueness
2. **Data availability** — sufficient quality + access
3. **Stakeholder appetite** — sponsorship + budget/priority

Missing any one → treat as a hype-risk flag, not a genuine opportunity.

### Genuine Opportunity vs Hype-Driven Pilot
| Genuine Transformation | Hype-Driven Pilot |
|---|---|
| Validated internal pain point | No defined problem |
| Executive sponsorship | Weak/no sponsorship |
| Measurable ROI target | 'Innovation theater' framing |
| Maps to drafting/summarization/research | Chosen because "AI is trendy" |

### Core Generative AI Capability Categories (for mapping pain points)
- **Drafting** — first-pass content generation (emails, ads, SOPs, commentary)
- **Summarization** — condensing unstructured/long-form input
- **Research/Synthesis** — aggregating and synthesizing information for decision-making

Exam pattern: given a function's pain point, pick the capability category above — reject unrelated categories like image generation, predictive analytics, or anomaly detection unless explicitly relevant.

### Leadership Framing Vocabulary
- **Opportunity mapping** = strategic exercise matching pain points to capability categories across functions
- **Use case** = single scoped instance within that mapping
- Favor opportunity-mapping language when presenting cross-functional AI strategy to executives.
