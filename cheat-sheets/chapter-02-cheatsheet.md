# Chapter 2 Cheat Sheet: Prioritizing High-Value Use Cases

## The Prioritization Matrix (Value x Feasibility)

| Quadrant | Value | Feasibility | Action |
|---|---|---|---|
| Flagship | High | High | Fund and pilot now |
| Quick win | Low | High | Fast, low-governance greenlight |
| Strategic bet | High | Low | De-risk (data, sponsorship) then pilot |
| Reject | Low | Low | Remove from roadmap |

**Value axis inputs:** revenue impact, cost savings, risk reduction, competitive differentiation.
**Feasibility axis inputs:** data readiness, technical complexity, regulatory/risk exposure, stakeholder sponsorship, existing infrastructure.

## Quick Wins vs Strategic Bets

| Attribute | Quick Win | Strategic Bet |
|---|---|---|
| Timeline | Weeks | Quarters+ |
| Data needs | Already available/clean | May need investment |
| Risk | Low | Higher |
| Value | Modest | Large / transformational |
| Portfolio role | Build momentum, prove value fast | Long-term differentiation |

**Rule of thumb:** a healthy pilot slate mixes both — quick wins alone under-deliver strategically; strategic bets alone create long dry spells with no proof points.

## Feasibility Inputs Checklist
- Data readiness: structured? accessible? quality/tagging in place?
- Risk: regulatory, reputational, safety exposure
- Sponsorship: is there an engaged, accountable business owner?
- Effort: integration complexity, model/infra requirements

## Avoiding Pilot Paralysis
- Root cause: pilot count exceeds evaluation/governance capacity.
- Symptom: pilots stall with no go/no-go decision.
- Fix: cap concurrent pilots to team capacity; stagger launches; assign clear decision owners and criteria per pilot before it starts.

## Portfolio Balancing
- Spread pilots across functions (e.g., support, finance, ops, marketing) rather than clustering in one department.
- Mix quick wins + strategic bets within the same portfolio cycle.
- Revisit portfolio balance each cycle as pilots conclude.

## Down-Selection Criteria (Long List → Shortlist)
1. Score value + feasibility for every candidate.
2. Filter out low/low quadrant items immediately.
3. Apply portfolio lens: ensure functional diversity, quick-win/strategic-bet mix.
4. Break ties using sponsorship strength and clarity of ownership.
5. Cap shortlist to organizational evaluation capacity (avoid pilot paralysis).

## Exam Traps
- Choosing highest value alone, ignoring feasibility → wrong.
- Treating sponsorship as optional "soft" factor → wrong; it's a core feasibility input.
- Approving many parallel pilots to "move fast" → causes pilot paralysis.
- Assuming data readiness doesn't matter because "generative AI handles any data" → wrong; poor readiness raises effort/risk.
