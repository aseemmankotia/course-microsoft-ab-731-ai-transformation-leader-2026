# Chapter 7 Lab: Agents, the Agent Store, and Microsoft Foundry at a Leadership Level

**Estimated time:** 15 minutes

## Exercise

Read-and-think exercise: given 3 scenarios, decide whether to source an agent from the Agent Store, commission a Copilot Studio build, or escalate to a Microsoft Foundry-based initiative

## Key takeaway

Use the Agent Store for vetted pre-built agents, reserve Foundry-level awareness for platform-scale custom initiatives, and always govern what actions an agent is authorized to take.
