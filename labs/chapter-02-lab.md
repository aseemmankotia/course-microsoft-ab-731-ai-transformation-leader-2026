# Chapter 2 Lab: Identifying and Prioritizing High-Value Use Cases

**Estimated time:** 20 minutes

## Exercise

Read-and-think exercise: given 10 candidate use cases across functions, plot each on a 2x2 value/feasibility matrix and select the top 3 for pilot with written justification

## Key takeaway

Prioritize AI use cases on both business value and feasibility, and constrain the number of simultaneous pilots to what change-management capacity can actually support.
